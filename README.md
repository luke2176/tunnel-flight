# 터널 플라이트 (Tunnel Flight)

Canvas 기반 1인칭 터널 비행 장애물 회피 게임.

**플레이:** https://luke2176.github.io/tunnel-flight/

## 조작
- `W` `A` `S` `D` / 방향키로 조종
- 화면을 누른 채 움직이면 조이스틱 (모바일/마우스)
- `1` `2` `3` 난이도 선택 · `Space` 출발 · `Esc` 일시정지 · `M` 음소거

## 특징
- 난이도 3단계 (하 / 중 / 상), 난이도별 최고 기록 저장
- 통과 가능한 통로를 항상 보장하는 공정한 장애물 생성
- 주사율과 무관하게 동일한 플레이를 보장하는 고정 타임스텝
- 구슬 획득 · 아슬아슬 통과 보너스
- `prefers-reduced-motion` 지원 (멀미·광과민성 완화)

단일 HTML 파일로 동작하며 외부 의존성이 없습니다.
